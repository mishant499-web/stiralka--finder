# Stiralka Finder

Telegram-бот для поиска объявлений о стиральных машинах под ремонт в Екатеринбурге.

## Что заложено в проект

- Проверка публичных RSS/Atom-лент по расписанию Vercel Cron (раз в 10 минут).
- Фильтр по стиральным машинам, признакам неисправности, упоминанию Екатеринбурга и цене до 3 000 ₽ или бесплатной отдаче.
- Уведомления в Telegram.
- Защита от повторных уведомлений через Upstash Redis.

**Важно:** это основа RSS-мониторинга, а не готовый парсер Avito. Avito может ограничивать автоматизированный доступ; не обходи капчи, авторизацию или технические ограничения. Нужны доступные публичные RSS/API-источники. Фильтр города использует слова в тексте объявления и пока не гарантирует точный радиус 10 км.

## 1. Разверни проект на Vercel

1. Открой https://vercel.com/new
2. Импортируй GitHub-репозиторий `mishant499-web/stiralka--finder`.
3. Нажми Deploy.

## 2. Добавь переменные окружения в Vercel

В Project → Settings → Environment Variables добавь:

- `TELEGRAM_BOT_TOKEN` — токен от BotFather. Не публикуй его и не отправляй в чаты.
- `TELEGRAM_CHAT_ID` — твой личный chat ID.
- `CRON_SECRET` — длинная случайная секретная строка.
- `RSS_FEEDS` — публичные RSS/Atom URL, разделённые точкой с запятой.
- `UPSTASH_REDIS_REST_URL` — REST URL базы Upstash Redis.
- `UPSTASH_REDIS_REST_TOKEN` — REST token базы Upstash Redis.

После добавления переменных сделай Redeploy.

## 3. Подключи Telegram

1. Открой бота: https://t.me/StiralkaFinderBot
2. Нажми Start.
3. После развёртывания скопируй домен проекта Vercel.
4. Установи webhook, подставив домен проекта и токен бота в адрес ниже. Не отправляй эту ссылку никому:

```
https://api.telegram.org/botТВОЙ_ТОКЕН/setWebhook?url=https://ТВОЙ_ПРОЕКТ.vercel.app/api/webhook
```

5. Напиши боту `/start`. Он покажет chat ID.
6. Добавь этот ID как `TELEGRAM_CHAT_ID` в Vercel и сделай Redeploy.

## 4. Настрой защиту от дублей

Создай Redis database на https://upstash.com/ и скопируй REST URL и REST Token в переменные Vercel.

## 5. Добавь RSS-источники

В `RSS_FEEDS` укажи адреса публичных RSS/Atom-лент, которые разрешено использовать. Несколько адресов разделяй точкой с запятой. Если источник не предоставляет RSS или API, проект пока не сможет получать оттуда объявления. Не добавляй страницы, требующие входа в аккаунт.

## Ограничения

- Расписание Vercel Cron зависит от тарифа и ограничений Vercel; проверь доступность интервала 10 минут в своём аккаунте.
- Объявления с неуказанной ценой автоматически не проходят фильтр.
- Для точного радиуса 10 км нужен источник с координатами объявлений и геокодирование.
- Перед поездкой проверяй, что объявление ещё доступно.
